# Проектная работа: «Посмотри в окно»

Учебный проект, выполненный в рамках курса «Веб-разработчик» в Яндекс Практикуме.

## Функциональность
- Верстка по макету Figma.
- Кастомные элементы форм (чекбоксы, кнопки).
- Состояния интерактивных элементов (`:hover`, `:active`, `:focus-visible`).
- Адаптивная сетка на Flexbox.

## Технологии
- HTML5
- CSS3 (Flexbox, кастомные свойства, БЭМ)
- JavaScript (базовая логика из заготовки)
